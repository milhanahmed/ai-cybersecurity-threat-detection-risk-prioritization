# Qualitative Usability Review

The integrated analyst dashboard was reviewed against five prototype usability criteria using a 1-5 scale (1 = poor, 5 = excellent).

| Criterion | Score | Rationale |
|---|---:|---|
| Clarity of purpose | 5 | Page title and introductory text identify the cybersecurity risk-prioritization purpose. |
| Input simplicity | 4 | The event form exposes the minimum demonstration fields in one view. |
| Output clarity | 4 | Prediction, confidence, risk score, and priority are visible in the latest-output area and event history. |
| Navigation efficiency | 5 | The prototype is a single-page workflow with no multi-page navigation. |
| Error prevention | 4 | Required HTML fields and constrained numeric/select inputs reduce invalid entry, while server validation remains authoritative. |

Mean qualitative usability score: **4.4/5.0**.

This is a formative developer evaluation, not a controlled end-user usability study. Future work should use representative security analysts, task-completion time, System Usability Scale (SUS), and qualitative interviews.
